# セイシュン・クエスト（PoC）

「何気ないあの瞬間が僕らの青春だ」をテーマにしたブラウザRPGのPoC。

MMOで過ごしたあの頃の「はじめて」の瞬間——冒険の始まり、職業選択、初ボス討伐、初レアドロップ、仲間とのダンジョン攻略、ソロだけど誰かがいる夜——を体験すると、その場面のスクリーンショットがポラロイド写真として「思い出アルバム」に記録される。

## 遊び方

`index.html` をブラウザで開くだけ（ビルド・サーバ不要の1ファイル構成）。

| 操作 | キー |
|---|---|
| 移動 | 方向キー / WASD |
| 決定・話す・調べる | Z / Enter |
| 思い出アルバム | M |

タッチデバイスでは画面下に仮想パッドが表示される。

## 流れ（15分程度）

1. はじまりの街に降り立つ → ギルド（灯りのある扉）で職業を登録
2. 東の草原でスライム退治（レアドロップあり）
3. 3匹倒すとボス「グラスキング」が出現
4. ボス討伐後、北の祠が開く。ミナとジンが仲間に加わりダンジョンへ
5. 最深部の「深淵の番人」を倒すと、夜の広場のたき火へ——

集めた瞬間は6つ。すべてポラロイドでアルバムに残る。

## 技術メモ

- 依存なしの素のHTML/Canvas/JS 1ファイル
- 320×208のピクセルキャンバスをCSSで拡大（`image-rendering: pixelated`）
- 思い出は `canvas.toDataURL()` でその瞬間の画面をそのまま写真化
- 効果音はWebAudioの矩形波のみ
