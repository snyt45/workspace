# 読書版

素材を要約するのではなく、記事として書き直す。
読者がノートを読むだけで、原典を見返さなくても内容を完全に理解できるようにする。

## 構成

- `## 概要`: 核心的な論題と結論を1段落で書く。
- テーマごとの `##` 小節: 素材の内容に沿って詳しく展開する。
  - 方法・フレームワーク・プロセスは、ステップや段落に書き直す。
  - 重要な数字・定義・発言は原語のまま残し、括弧内に日本語の注釈を付ける。
- `## Framework & Mindset`: 素材から抽象化できるフレームワークと考え方を、ステップや段落で書く。

分量は素材に合わせる。
長い素材では、各小節と各フレームワークを目安1000字以上にする。
短い投稿では、小節や Framework & Mindset を省いてよい。膨らませるために素材に無いことは書かない。

## 制約

- 高度に要約しない。
- 新しい事実を足さない。曖昧な記述は原意を保ち、不確かだと明記する。
- 固有名詞は原語のまま残す。訳せるものは括弧内に日本語訳を付ける。
- 長い段落は、論理のまとまりごとに bullet に分ける。
- 字数などの指示そのものを本文に書かない。
- 素材を取得できなければ、推測で書かずに「取得できなかった」と返して終える。
