# 生成物の形式

`template.html` の `__SRC__` / `__META__` を置換し、`~/annotations/YYYY-MM-DD-<slug>.html` に書き出す。slug は主対象ファイル名（例: `csv-rb`）。ディレクトリがなければ作成する。テンプレート内部の理解は不要。置換だけで動く。

## __SRC__: 対象コード全文

注釈箇所だけをマーカーで囲む。

- 開き `⟦id⟧`、閉じ `⟦⟧`。id は `[A-Za-z0-9_-]` のみ。エスケープ不要。
- スパンは構文単位で最小に。ネスト不可（入れ子になる構文は外側だけ囲み、内側は別の出現箇所で囲むか外側カードで触れる）。
- 同じ構文は同じ id で全出現をマーク。カードは初出の行に付き、2回目以降はカードへの誘導になる。実例は代表1つでよい。
- 複数ファイルは各ファイルの先頭に `⟪path⟫` 行を置く。行番号はファイルごとにリセット。
- PR 全体が対象なら diff のファイルを全件含める。並び順は呼び出し経路順（入口側を先に）。本題と無関係なファイルは載せない。
- ハイライトはファイル拡張子から自動判定（Prism）。未知の拡張子は素のまま表示。

## __META__: JSON

JSON 内の `"` は `\"`。

```json
{"title":"scripts/link.sh","lang":"zsh","summary":"1〜2文の要約",
 "entry":{"stack":[{"t":"mise run link","loc":"mise.toml:12"},{"t":"scripts/link.sh"}]},
 "flow":{"intro":"呼び出しを受けたコード経路:",
         "steps":[{"t":"EXCLUDE に無ければリンク対象","f":0,"l":58}],
         "fig":{"rows":[["~/.zshrc.d/alias.zsh","リンク","~/.dotfiles/zsh/.zshrc.d/alias.zsh"]],
                "caption":"任意"}},
 "issues":[{"f":0,"line":57,"text":"実際に踏みうる問題だけ。無ければ空"}],
 "trace":[{"f":0,"line":15,"text":"src = リンク対象9件を1行ずつ。出どころ","ref":27}],
 "ann":{
  "id1":{"lv":1,"name":"構文名","what":"正確な1文（〜60字）","ex":"任意: 実例1行"},
  "id2":{"lv":2,"name":"構文名","syn":"一般形","what":"正確な操作記述1〜2文",
         "ex":"入力 → 出力 を実際の値で。\\n で複数行可",
         "ref":"任意: 公式リファレンスの該当セクションURL"}}}
```

- `title` / `lang` / `summary`: 見出し・言語・機能の核心（1〜2文）。核心は summary に1回だけ書く。
- `entry`（呼び出し経路）と `flow`（処理の流れ）: 書き方は `meta.md`。
- `issues`: `[{"f":0,"line":57,"text":"..."}]`。該当行の横に ⚠ カード。
- `trace`: `[{"f":0,"line":57,"ref":27,"text":"..."}]`。ref は出どころ行。青マークで表示。
- `ann`: 注釈カード。書き方は `content.md`。
  - L1 で使えるキーは `name/what/ex` のみ。
  - L2 は `syn`（一般形）と `ref`（公式リファレンス）を足せる。
- `entry` / `flow` / `issues` / `fig` / `ref` は任意（無ければキーごと省略）。
- 複数ファイル時の行参照は `{"f":1,"l":44}` / `{"file":1,"line":44}`（省略時は最初のファイル）。
- 見出しの既定は「呼び出し経路」「処理の流れ」。`entry.title` / `flow.title` で変更可。
