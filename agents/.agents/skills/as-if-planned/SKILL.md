# as-if-planned

対話の積み重ねで形になった文書を、会話を見ていない読者がそのまま読める最終版に書き直す。

## 前提

会話は制作過程であり、成果物の一部ではない。読者はこの文書がどう議論され、どう修正されてできたかを知らない。

書き直した文書は**最初からこの形で計画されていた**ように読めなければならない。

## 原則

### 読者を新規参加者にする

読者はこれまでの議論・修正指示・前提を何も知らない。前提の共有や用語の定義が必要なら文書内に明記する。前知識を前提にしてよい箇所があれば、それは設計として成立する情報だけ。

### 会話に依存する文を残さない

次に含まれる文を取り除くか、読者が必要とする内容へ書き換える。

- 指示・依頼: 「最終設計を〜してください」「全面的に書き直して」
- 議論の痕跡: 「先ほどの話から」「前回の指摘で」「ご指摘の通り」「この会話では」「当初は〜だったが」
- 修正の記録: 「〜に変更した」「〜を追加した」「旧版では〜」
- 参照先が会話を指す文: 「前述の通り」（文書内の参照なら可）

機械的に消すのではなく、読者が必要とする情報まで消さない。

### 計画された最終版として書く

- 決定事項を「決めた経緯」ではなく「設計」として宣言的に書く。
- 代案や保留は、読者が決断に必要な場合のみ残す。
- 時系列ではなく構造で並べる。構成は論理フローに従う。

## 手順

1. 元文書を読み、会話に依存する文と、読者が必要とする内容を分ける。
2. 会話依存の文を、設計の内容に翻訳するか、削除する。
3. 構造を、最初から計画された最終版として組み直す。
4. 読者が新規参加者でも意味が通じるか、一文ずつ確認する。

## 出力

書き直した最終版を返す。経緯や差分説明は添えない。
