# ELI5

そのトピックについて何も知らない人向けに、**大きな図と最小限の文章**で構成されたHTML Artifact 1枚で説明する。

説明対象はユーザーの依頼（`/eli5 <テーマ>` の引数）に従う。

## 形式

- 自己完結した1つのHTMLファイル（CSS・SVGはインライン）として出力する
- 大きなSVG図解を最低3つ入れる。矢印付きフロー図・構成図などで「何が登場するか」「情報がどこからどこへ流れるか」「各部分の役割」を視覚化する
- 文章は短く、専門用語は避け、使う場合は一言で言い換える
- 1ページで全体像が把握できるようにする
